# ClimateChange_Android_App
An Android application for monitoring global climate change and global warming using Kotlin. Provides data visualization, alerts, and research tools for researchers, students, and decision-makers.

## What I added
- Minimal Android Studio project skeleton (app module) with a MainActivity and simple layout.
- Gradle project files (settings.gradle, build.gradle, gradle.properties).

## How to run (Windows / Android Studio)
1. Clone the repo:
   git clone https://github.com/fazeli1977-dot/ClimateChange_Android_App.git
   cd ClimateChange_Android_App

2. Open Android Studio → Open an existing project → select the cloned folder.

3. Let Android Studio sync Gradle. If asked to install the Gradle wrapper or components, accept.

4. Create an Android Virtual Device (AVD) if you don't have one: Tools → AVD Manager → Create Virtual Device.

5. Run the app (green Run button). The sample "Hello" screen should appear in the emulator.
